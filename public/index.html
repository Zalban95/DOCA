MCP Servers

        
        
      

      

        Model Context Protocol servers. A running server's tools are offered to the
        DOCA harness alongside its built-in ones, named
        mcp__server__tool, and each can be switched off in the harness ⚙ panel.
        Only running servers contribute tools, and nothing is started unless you say so.
        Servers are grouped by the machine they act on: this host, or a paired client — and once
        a client is in play the harness is told which machine each tool reaches, so you can ask
        for something "on my PC" and get the right one.

What may run without asking

    

      In Manual the agent is stopped before each tool call that does something, and you
      answer it in the chat. Saying always allow puts the command type on this list — so
      shell: git stops being a question while shell: rm is still asked every time.
      A command that builds itself at run time can never join the list.
      Reading this panel's own state never asks. In Auto nothing is asked at all.

Specialist

    

      A specialist is its prompt plus a short tool list. Keep both small — it runs its own
      steps, and everything you add here it pays for on every one of them.
      role is the system prompt, tools is an allowlist,
      memory false means it searches memory rather than carrying it,
      and provider/model are optional: leave them out and it uses
      the panel's. Three tools can never be granted here — changing settings, installing
      anything, or dispatching another specialist — and are removed if you ask for them.
